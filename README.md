# FormA: як інтегрувати формувальне оцінювання в освітню практику

Статичний сайт курсу: `index.html` + папка `img/`. Сервер і збірка не потрібні.

## Як опублікувати на GitHub Pages

1. Створіть репозиторій (наприклад, `forma-course`) або папку в наявному репозиторії.
2. Завантажте в нього `index.html`, `README.md` і всю папку `img/`, зберігши структуру.
3. Settings → Pages → Source: **Deploy from a branch**, гілка `main`, папка `/ (root)` (або `/docs`, якщо файли лежать там).
4. За хвилину-дві сайт буде доступний за адресою `https://<ваш-логін>.github.io/<репозиторій>/`.

## Що змінюється на GitHub Pages порівняно з claude.ai

- Відео YouTube відтворюються просто на сторінці (на claude.ai вони відкриваються в новій вкладці).
- Позначки «виконано», нотатки, відповіді у формах самооцінювання, результати тестів і чернетки відгуків зберігаються в браузері кожного учасника (localStorage) і нікуди не надсилаються.

## Підтвердження проходження

- Учасник на сторінці «Підтвердження проходження» (`#cert`) бачить залікові пункти: 1.1, тести 1.6 / 2.8 / 3.4 / 4.3 (≥70%), 4.4 і форму відгуку. Коли все виконано, він вводить свою адресу й отримує код вигляду `FA-261111-MSFJ-8VD4` (у коді є дата завершення).
- Тренер відкриває сторінку «Матеріали для тренерів» (`#materials`), вставляє рядки «адреса код» своєї групи і бачить ✓ / ✗ для кожного.
- Код обчислюється в браузері (HMAC адреси та дати). Він захищає від помилок і випадкових підробок, але не від людини, яка розбереться в коді сторінки.

## Доступ до курсу

- Курс відкривається лише після введення адреси зі списку доступу. Тексти курсу й матеріали тренерів у `index.html` зашифровані.
- Списки: `access/learners.txt` (слухачі) і `access/trainers.txt` (тренери). У файлах немає самих адрес, лише зашифровані рядки, тож їх можна тримати в публічному репозиторії.
- Нові рядки створює помічник «Доступ до курсу» на сторінці «Матеріали для тренерів». Рядки дописують у кінець потрібного файлу (Edit → вставити → Commit changes).
- **Оновлюючи сайт, не завантажуйте папку `access` повторно:** інакше зникнуть рядки, які ви дописали. Зазвичай достатньо замінити `index.html`.
- Список адрес тренерів і слухачів зберігайте окремо в себе (не в репозиторії).

## Посилання на платформу

Кнопки до форумів ведуть на `uatnextgen.euacademy.fpfis.tech.ec.europa.eu`. Якщо курс переїде на іншу адресу, замініть цей домен пошуком і заміною в `index.html`.
